# Native 65K tokenizer

This C++17 extension executes the reviewed Terminus router, ordered English
BPE, scored Indic BPE, and contextual decoder. It is not the stock HF export.
It returns little-endian uint16 buffers and checks every document against its
NFC-normalized source text. It does not insert BOS, EOS, PAD or EOD.

Install in a CPU environment from the repository root:

```bash
python -m pip install 'regex==2026.7.19' 'unicodedata2==16.0.0' \
  'pybind11==3.0.1' 'setuptools==80.9.0'
python -m pip install --no-build-isolation ./native/tokenizer65k
python -m unittest tests.test_tokenizer_native tests.test_tokenizer_revision
```

Python 3.14 already supplies Unicode 16; older supported versions use the
pinned `unicodedata2` library. The wrapper checks the versions rather than
silently accepting a different router. The C++ scissors engine uses Unicode
property tables generated by the pinned regex library. No fast-math compiler
flags or vocabulary retraining are involved.

Use `Native65kTokenizer(path, expected_sha256=reviewed_sha)` from
`terminus.tokenizer_native`. `encode_batch_bytes(texts)` returns one verified
buffer per source document. Run one process per physical CPU core initially;
measure before using SMT siblings. Native caches are bounded, and workers reuse
the compiled vocabulary. No PyTorch import or GPU is required.

Run the source conversion tool with an external, pinned plan:

```bash
python -m production.native_corpus --plan /external/PLAN.json \
  --work-root /external/work
```

Each job names one original source object, its ETag and size, explicit text
columns/rendering rules, and disjoint original selection indices with explicit
train/validation membership. One source is read once for all its parts. A
changed source, missing document, ambiguous UUID, malformed text, invalid index,
or round-trip failure rejects that job. There is no fallback through old decoded
tokens. `runtime_files` pins implementation files; the compiled binary and
Unicode tables are recorded in each encoder identity.

Set `resume_verified` to reuse only receipts whose contract, source snapshots,
and durable output checksums still match. Set `clean_work` to remove local files
after the result is durable. S3 permissions need read access to named inputs,
read/write to the campaign output prefix, and `ListBucket` so missing completion
markers return 404 rather than an ambiguous access-denied error. Workers must
have independent termination deadlines supplied by the CPU fleet launcher.

Content-addressed output bins, document indices and receipts are immutable.
Progress/completion pointers are separate. Conversion does not qualify a
training corpus by itself: cross-source holdout/family reconciliation, exclusion
policy, quota recounting, and final curriculum packing are separate gates.
Do not publish a manifest merely because all tokenization jobs completed.

The benchmark must include Parquet reading, indexing, S3 transfers and output
verification. A tokenizer-kernel rate is not an end-to-end fleet rate. Spot
interruptions replay one unfinished source job; completed jobs are verified and
skipped. No training GPU campaign is launched by this package.
