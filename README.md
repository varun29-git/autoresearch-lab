# Terminus autoresearch

This standalone Terminus research repository combines the completed architecture and dense speed campaigns with the production CI-1 integration under evaluation. The older architecture, speed, and HPO campaigns remain available for provenance; their run configurations are not production launch configurations.

The production handoff does not start a paid GPU run or assert that the 32-GPU throughput target has been reached. Architecture evidence is in [the final campaign report](notes/FINAL_REPORT_ARCHITECTURE_20261006.md), and kernel evidence is under [docs/speed](docs/speed/README.md).

The handoff does not start a paid GPU run or assert that the 32-GPU throughput target has been reached. Data manifests, token shards, checkpoints, credentials, and trial results remain outside Git.
