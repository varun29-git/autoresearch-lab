# Source baseline

This repository began as a clean tracked-file snapshot of private `varun29-git/terminus-modeltunnelv2` commit `353ecc32e8c5d7bd1d1eb29a461962519c1553de` (2026-10-05). The source repository's uncommitted architecture-report drafts, local training data, evaluation records, and run outputs were not copied.

The architecture-research workflow is adapted from Andrej Karpathy's [autoresearch](https://github.com/karpathy/autoresearch) at commit `228791fb499afffb54b46200aca536f79142f117` (inspected 2026-10-05). No upstream Python source was copied. The analogous parts here are `program.md`, a protected preparation/evaluation contract, an agent-editable model surface, short repeated experiments, and an append-only keep/discard ledger. The fixed five-minute objective was deliberately changed to matched token exposure because this stage selects architecture quality rather than speed.
