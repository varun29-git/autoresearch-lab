# Prior unit-normalization designs excluded from stage one

The old Terminus Transformer tests explored parameter-free Q/K UnitRMS and extra SubLN/branch normalization. This stage-one architecture search has a short GPU budget. Repeating those exact safety-first configurations would be a stupid use of it.

The archived 30B-token Test 17 used parameter-free Q/K RMS normalization. It completed without numerical divergence; sampled maximum attention logit was 7.761 and post-normalization vector RMS stayed within about 5.35e-5 of one in sampled means. That establishes *logit control*, not superior held-out quality. The earlier 10B-token Test 17 used learned **independent affine Q/K gains** that grew to roughly 14 and produced a sampled logit of 1,515, but precision, data, model and schedule also differed. It is not a causal learned-versus-unit comparison. The old fixed-scale UnitRMS path also differs from original QKNorm, which learns an attention scale. Thus neither archived run justifies treating fixed unit scale as an optimal architecture.

The completed Lean 150M dense-FP8 run and 2B-token QAT continuation removed SubLN and Q/K normalization entirely. It trained without non-finite incidents, though quality and first-layer behavior were imperfect. This is enough to reject the claim that extra forced-unit protections are *required* for the model to train. It does not prove every possible SubLN variant harms quality.

For this campaign, `research/policy.json` and `research/protocol.py` reject `qk_norm_mode="unit_rms"`; `candidate.json` sets `use_subln=false` for the baseline. Kimi must not recreate the same fixed-unit Q/K operation or parameter-free SubLN in editable model code. Learned-gain main block RMSNorm and final RMSNorm remain normal parts of the model. A novel normalization design may be proposed only if it changes the mechanism in a way the previous tests did not cover and states the quality/stability prediction before training.
